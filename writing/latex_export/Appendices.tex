\section*{Appendix A: Note on Supplementary Material}
\addcontentsline{toc}{section}{Appendix A: Note on Supplementary Material}

No calculation sheets, source code, or other supplementary material are
appended to this report. Per the WILP project report guidelines, the
source code of software need not be included in the report; the system's
architecture and implementation are described at the appropriate level
of detail in Chapters~3 and~4. All raw results, statistical test
outputs, and derived measures relevant to this dissertation's findings
are presented directly in the tables of Chapter~5, adjacent to their
discussion, rather than being deferred to an appendix. The complete
codebase, datasets, and result artefacts are maintained in the project's
version-controlled repository described in Section~4.1.
